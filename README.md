# Blackcoffer AI Textual Analysis Assignment

## Project Overview

This project is based on the Blackcoffer AI Textual Analysis assignment. The main objective is to extract article content from the given URLs and perform text analysis using Python.

The program reads the article URLs from `Input.xlsx`, extracts the title and main content of each article, and saves the extracted text in separate `.txt` files. It then calculates the required sentiment analysis and readability variables and stores the results in `Output.xlsx`.

I divided the work into two main parts: extracting the article data and analyzing the extracted text.

## Files and Their Purpose

### 1. `main.py`

This is the main Python file that runs the complete pipeline. It reads the input Excel file, scrapes the articles, saves their text, performs the analysis, and generates the final output workbook.

I kept the main operations in one file so that the complete process can be executed using a single command.

### 2. `Input.xlsx`

This file contains the article IDs and URLs provided in the assignment. The program uses these URLs to identify which articles need to be extracted and analyzed.

### 3. `Output Data Structure.xlsx`

This file provides the required structure for the final output. I used it as a reference to maintain the correct column names and column order in the generated Excel file.

### 4. `Text Analysis.docx`

This document explains the definitions and formulas for the 13 text analysis variables. I used it as the reference while implementing the calculations.

### 5. `Objective.docx`

This contains the assignment instructions, including the requirements for web scraping, text analysis, output generation, and documentation.

### 6. `StopWords/`

This folder contains the stopword lists provided with the assignment. These words are excluded from sentiment analysis according to the given methodology.

### 7. `MasterDictionary/`

This folder contains the positive and negative word dictionaries.

- `positive-words.txt` is used to calculate the positive score.
- `negative-words.txt` is used to calculate the negative score.

These dictionaries help identify positive and negative words in the extracted article text.

### 8. `scraped_test/`

This folder stores the extracted article text files. Each file is named using its corresponding `URL_ID`, making it easier to identify which article the text belongs to.

For example, `TrackerOPS29012026.txt` contains the extracted content for that article ID.

The current script uses this folder to store the text files, even though its name includes the word `test`.

### 9. `test_scraper.py`

I used this file during development to test whether the article title and main content could be extracted correctly from the webpages before processing the complete dataset.

### 10. `analysis_test.py`

This file was used to test and inspect the text analysis calculations separately. The complete pipeline is executed through `main.py`.

### 11. `Output.xlsx`

This is the final output generated by the program. It contains the original article ID and URL, along with the 13 calculated text analysis variables.

## How the Program Works

The program follows these steps:

1. Reads the article IDs and URLs from `Input.xlsx`.
2. Sends requests to the article webpages using Python.
3. Extracts the article title and main body while excluding unrelated webpage content where possible.
4. Cleans up spacing and saves the extracted text as a UTF-8 `.txt` file.
5. Loads the supplied stopword lists and sentiment dictionaries.
6. Processes the article text and calculates the required variables.
7. Stores the results in a pandas DataFrame.
8. Exports the final results to `Output.xlsx` using the required column order.

## Text Analysis Variables

The program calculates the following 13 variables as specified in the assignment.

| Variable | Description |
|---|---|
| POSITIVE SCORE | Counts words found in the positive dictionary after the specified cleaning process. |
| NEGATIVE SCORE | Counts negative dictionary matches and reports the score as a positive magnitude. |
| POLARITY SCORE | Measures the balance between positive and negative scores. |
| SUBJECTIVITY SCORE | Measures sentiment-related words relative to the total cleaned words used in the formula. |
| AVG SENTENCE LENGTH | Calculates the average number of words per sentence. |
| PERCENTAGE OF COMPLEX WORDS | Calculates the proportion of words classified as complex. |
| FOG INDEX | Calculates the readability value using the formula provided in the assignment. |
| AVG NUMBER OF WORDS PER SENTENCE | Calculates total words divided by total sentences. |
| COMPLEX WORD COUNT | Counts words containing more than two syllables. |
| WORD COUNT | Counts cleaned words after removing the specified English stopwords and punctuation. |
| SYLLABLE PER WORD | Represents the average syllable count per word as implemented in the program. |
| PERSONAL PRONOUNS | Counts the specified pronouns: I, we, my, ours, and us, while avoiding matches for the country abbreviation US. |
| AVG WORD LENGTH | Calculates the average number of characters per counted word. |

### Important formulas

**Polarity Score**

```text
(Positive Score - Negative Score) /
(Positive Score + Negative Score + 0.000001)
```

**Subjectivity Score**

```text
(Positive Score + Negative Score) /
(Total Words after cleaning + 0.000001)
```

**Average Sentence Length**

```text
Number of Words / Number of Sentences
```

**Percentage of Complex Words**

```text
Complex Word Count / Word Count
```

**Fog Index**

```text
0.4 * (Average Sentence Length + Percentage of Complex Words)
```

The formulas above follow the definitions in the supplied assignment document. The percentage of complex words is represented as a fraction in this implementation.

## Installation and Setup

Make sure Python is installed on your system.

Open PowerShell in the project directory and create a virtual environment if you do not already have one:

```powershell
python -m venv venv
```

Activate the environment:

```powershell

```

```powershell

```

## Limitations

- Article extraction depends on the structure of the source webpages. Changes to a webpage can require changes to the scraping logic.
- Dictionary-based sentiment analysis does not fully understand context, sarcasm, or negation.
- Syllable counting is approximate. The current implementation uses a pronunciation dictionary where available and a fallback heuristic for other words.
- Readability scores are indicators based on the specified formulas and should not be treated as complete measures of how easy an article is to understand.

## Conclusion

This project automates the extraction and analysis of the 82 articles provided in the assignment. It combines web scraping, text processing, dictionary-based sentiment analysis, readability calculations, and Excel report generation in a reproducible Python workflow.

The generated `Output.xlsx` provides a structured way to compare the articles using the required variables, while the individual text files preserve the extracted content for further inspection.
